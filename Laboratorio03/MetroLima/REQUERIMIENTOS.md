# Requerimientos Funcionales - Metro de Lima y Callao

## RF01 - Ver líneas disponibles

El sistema permitirá visualizar todas las líneas del Metro de Lima y Callao registradas en el programa.

## RF02 - Ver estaciones de una línea

El usuario podrá seleccionar una línea y el sistema mostrará todas sus estaciones en el orden correspondiente, además de la cantidad total de estaciones.

## RF03 - Buscar una estación

El usuario podrá ingresar el nombre de una estación y el sistema mostrará la línea o líneas a las que pertenece.

## RF04 - Ver estaciones cercanas

El usuario podrá seleccionar una estación y el sistema mostrará la estación anterior y la estación siguiente dentro de su línea.

## RF05 - Ver conexiones de una estación

El usuario podrá buscar una estación y el sistema indicará si permite realizar una conexión con otra línea del Metro.

## RF06 - Cómo llegar de una estación a otra

El usuario podrá ingresar una estación de origen y una estación de destino. El sistema mostrará la ruta que debe seguir y los cambios de línea necesarios, si los hubiera.

## RF07 - Filtrar estaciones por nombre

El usuario podrá ingresar una palabra o parte del nombre de una estación y el sistema mostrará todas las estaciones que coincidan con la búsqueda.

## RF08 - Ver información general del Metro

El sistema mostrará información general de la red registrada, como la cantidad de líneas, la cantidad de estaciones por línea, el total de estaciones y las estaciones que permiten conexión entre líneas.

## RF09 - Validar las búsquedas ingresadas

El sistema validará los datos ingresados por el usuario y mostrará mensajes cuando una línea, estación u opción no exista. Además, las búsquedas reconocerán diferencias entre mayúsculas, minúsculas y tildes.

## RF10 - Salir del sistema

El usuario podrá finalizar la ejecución del programa seleccionando la opción de salir.
