# Laboratorio 14 – Autenticación con Firebase

## Descripción

Aplicación móvil nativa para iOS desarrollada con Swift y SwiftUI, que integra Firebase para la autenticación de usuarios y la gestión de mensajes en tiempo real.

## Tecnologías utilizadas

- Swift
- SwiftUI
- Xcode
- Firebase Authentication
- Cloud Firestore
- Swift Package Manager

## Actividad 01 – Autenticación con Firebase

- Registro de usuarios mediante correo electrónico y contraseña.
- Inicio y cierre de sesión.
- Validación de credenciales.
- Gestión del estado de autenticación.

## Actividad 02 – Base de datos en tiempo real

- Envío y recepción de mensajes.
- Almacenamiento de mensajes en Cloud Firestore.
- Visualización del correo del remitente y la hora de envío.
- Sincronización de mensajes en tiempo real entre usuarios.

## Configuración

- Xcode 16.2 o posterior.
- iOS 16.0 o posterior.
- Firebase iOS SDK 11.15.0.
- Archivo GoogleService-Info.plist correspondiente al proyecto Firebase.
